# 体内おしごと大作戦 / Smart Black

Static playable LP, source in dist. Run npm run dev for preview.

Continuous 60-second 3D delivery game: proximity collection, visible cargo stack, automatic unloading, combos, magnetic collection and helper unlock. Three paused discoveries explain storage, insulin resistance and lipid metabolism on one map. Product features → CTA follows the game. No questionnaire or questionnaire eligibility.

The body model is a qualitative accelerated illustration of repeated daily patterns, not a medical simulation or an immediate effect of coffee. Product claims remain separately explained with their conditions.
